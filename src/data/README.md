# APRS device identification database

`aprs-deviceid.json` is an unmodified snapshot of the APRS device identification database generated 2026-11-16, from https://aprs-deviceid.aprsfoundation.org/tocalls.dense.json. Source and maintainers: https://github.com/aprsorg/aprs-deviceid. Licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/). Refresh the snapshot from that URL to pick up new allocations.

OpenBeacon currently identifies TOCALLs only; Mic-E device identifiers require separate decoding. OpenBeacon has been allocated TOCALL `APOBCN`.
