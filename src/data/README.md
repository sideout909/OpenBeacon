# APRS device identification database

`aprs-deviceid.json` is an unmodified snapshot of the APRS device identification database generated 2026-10-19, from https://aprs-deviceid.aprsfoundation.org/tocalls.dense.json. Source and maintainers: https://github.com/aprsorg/aprs-deviceid. Licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/). Refresh the snapshot from that URL to pick up new allocations.

OpenBeacon currently identifies TOCALLs only; Mic-E device identifiers require separate decoding. To request an OpenBeacon TOCALL, follow https://github.com/aprsorg/aprs-deviceid/blob/main/ALLOCATING.md and submit a request as the application developer. Until allocated, the generic APRS destination remains appropriate.
